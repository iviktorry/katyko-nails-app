# 💅 Nails by Katy — Commercial Landing Page

A bilingual (EN/RU) commercial landing page built for a beauty studio in Minsk. Designed to showcase portfolio works, display pricing, and process client inquiries via serverless email routing.

![Application Interface Screenshot](./src/assets/screenshot.png)

## 🔗 Links

- **Live Demo:** [View Live Site](https://katyko-nails-salon.vercel.app/)
- **Repository:** [View Source Code](https://github.com/iviktorry/katyko-nails-salon)

---

## Tech Stack & Libraries

- **Core:** React 18, Vite, Tailwind CSS
- **i18n:** `react-i18next` (English / Russian)
- **UI & Media:** `yet-another-react-lightbox`, Lucide React
- **Form Handling:** Web3Forms API (Serverless email delivery)

---

## Key Features & Highlights

- **Bilingual Support (i18n):** Instant EN/RU toggle via `react-i18next`.
- **Dynamic Portfolio Grid:** Responsive gallery logic with breakpoint-based image slicing and "Show More" toggle.
- **Full-Screen Lightbox:** Touch-swipeable interactive image preview module.
- **Serverless Contact Form:** Direct-to-inbox async form handling using Web3Forms API with auto-dismissing toast feedback.
- **Accessible UI:** Accessible notification overlays with dynamic `aria-live="polite"` feedback for screen readers.
